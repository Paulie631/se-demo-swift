2 · Demo policy in ZIA

Creates a custom URL category for Quick's domains, an SSL inspection rule that decrypts it, a Caution rule (usage-policy coaching page) and a Block Web DLP rule (PCI / PII / GLBA), then activates.

Scope it to a test user (recommended: the rules then affect no one else) · everyone
Create works on tenants whose users live in ZIA's hosted database. With an IdP or ZIdentity, create the user there and use it here. Sign in to Client Connector on the demo machine as this user.

Generate Amazon Quick traffic

    
Sends Quick-shaped requests from this laptop through Client Connector. All data is synthetic. Requests carry no AWS credentials, so AWS answers with an error code, but ZIA inspects, logs or blocks each one first. Run a few passes 30–60 minutes before a demo so the dashboards have data.

2 · Deploy & wire to Quick

      
    
        
  1. Press Deploy stack (or upload the downloaded template in CloudFormation yourself). The outputs appear under the button.
    2. 
        
  2. Quick console: give Quick access to the stack's DataBucketName, then create an S3 knowledge base on it and add it to a chat agent or Space.
    3. 
        
  3. Quick console › Integrations › MCP: URL = McpServerUrl, service auth None (or a custom Authorization: Bearer … header if you set a token). MCP integrations need Quick Enterprise.
    4. 
        
  4. ZPA path: create an app segment for <region>.quicksight.aws.amazon.com (TCP 443) on the new connector group.
    5. 
        
  5. Delete the stack after the demo. The bucket is emptied automatically.
